# Smart Review Test Tracker — 설계 문서

> **작성일:** 2026-06-11  
> **버전:** v1.0  
> **목적:** Smart Review 신규 버전 성능 풀테스트를 대리 인원이 수행하고, 해외 출장 중인 담당자가 원격으로 테스트 내역을 실시간 공유받고 피드백을 줄 수 있는 웹 기반 도구

---

## 1. 개요

### 배경

- Smart Review 신규 개발 버전 출시 시 성능 풀테스트 필요
- 담당자 해외 출장 중 대리 테스터가 본사에서 테스트 수행
- 기존: 엑셀/메신저 기반 수동 공유 → 실시간 동기화 불가, 히스토리 관리 어려움

### 목표

- 실시간 양방향 동기화로 동일 화면 공유
- 영구 기록 보관 → 지식 자산화
- 관리자 주도 사용자/권한 관리

## 3. 권한 체계

### 4단계 역할

| 역할 | 권한 |
|------|------|
| **Viewer** | 테스트 결과 조회, 기록 보관소 열람 |
| **Tester** | Viewer + 테스트 결과 입력/수정, 피드백 작성 |
| **Reviewer** | Tester + 카테고리/항목 관리 (추가·수정·삭제·순서변경), 세션 생성/관리 |
| **Admin** | Reviewer + 사용자 승인/권한 관리, 세션 재오픈, 시스템 설정 |

### 사용자 관리 흐름

1. 신규 사용자가 회원가입 요청
2. **"관리자 확인 필요"** 상태로 대기
3. Admin이 승인 + 역할 부여
4. 승인된 사용자는 영구 이용 가능 (별도 만료 없음)
5. Admin은 언제든 특정 인원의 권한 수준 변경 가능
6. 인원 제한 없음 — Admin 승인 시마다 사용자 증가

## 4. 데이터 구조

### 계층 구조

```
테스트 세션 (Test Session)
  ├─ 대상 버전 (SW Version Info)
  │    ├─ Vision PC (5개 SW)
  │    ├─ Review PC (4개 SW)
  │    └─ AI Model Management (1개 SW)
  └─ 테스트 영역
       └─ 카테고리 (자유 생성)
            └─ 테스트 항목
                 ├─ 결과 (Pass/Fail/N/A/미진행)
                 ├─ 비고 + 첨부 (인라인 이미지)
                 └─ 피드백 스레드 (무제한 댓글 체인)
```

### 테스트 세션

| 필드 | 설명 |
|------|------|
| 세션명 | 예: "Smart Review 2.10 Full Test" |
| 상태 | Draft → In Progress → Completed |
| 생성일 / 완료일 | 자동 기록 |

### 대상 버전 (세션 내 구조화)

세션 생성 시 아래 구조가 자동 세팅되며, 각 SW의 버전명을 직접 입력합니다.

```
📦 Vision PC
  ├─ AOIGUI - Halcon        [버전 입력란]
  ├─ AOIGUI - FastRed       [버전 입력란]
  ├─ ONNX Model             [버전 입력란]
  ├─ Base Library            [버전 입력란]
  └─ Graphic Driver          [버전 입력란]

📋 Review PC
  ├─ Review Station 3        [버전 입력란]
  ├─ AI SmartGate V2         [버전 입력란]
  ├─ SROCV                   [버전 입력란]
  └─ Base Library            [버전 입력란]

🤖 AI Model Management
  └─ AI Model Management Tool [버전 입력란]
```

- portal-data.json 연동으로 최신 버전 자동 불러오기 가능

### 카테고리

| 필드 | 설명 |
|------|------|
| 카테고리명 | 기능별 그룹 (자유 입력) |
| 설명 | 선택사항 |
| 순서 | 드래그로 정렬 가능 |

### 테스트 항목

| 필드 | 설명 |
|------|------|
| 항목명 | 자유 입력 |
| 설명 | 테스트 방법/기준 (선택) |
| 결과 | Pass / Fail / N/A / 미진행 |
| 비고 | 자유 텍스트 |
| 첨부 | 이미지 인라인 표시 (클립보드 붙여넣기, 드래그앤드롭) |
| 순서 | 드래그로 정렬 가능 |

### 피드백 스레드

- 각 테스트 항목에 무제한 댓글 체인
- 댓글에도 이미지 인라인 첨부 가능
- 작성자 / 시간 자동 기록

## 5. 실시간 동기화 & 알림

### WebSocket 동기화

모든 변경사항이 즉시 상대방 화면에 반영됩니다.

| 이벤트 | 동작 |
|--------|------|
| 테스트 결과 입력/수정 | 상대방 화면 즉시 갱신 |
| 피드백 댓글 작성 | 실시간 표시 + 알림 배지 |
| 이미지 첨부 | 업로드 완료 즉시 인라인 표시 |
| 카테고리/항목 추가·삭제 | 즉시 반영 |
| 세션 상태 변경 | 즉시 반영 |

### 알림

- 화면 우측 상단 **알림 벨** — 새 피드백, 결과 변경 시 빨간 배지
- 클릭하면 해당 항목으로 바로 이동
- 브라우저 탭 타이틀에 `(3) Smart Review Tracker` 식으로 미확인 건수 표시

### 접속 상태

- 현재 접속 중인 사용자 목록 표시 (아바타 또는 이름)
- 오프라인 동안 변경된 내역은 재접속 시 자동 갱신

## 6. 기록 보관소 & 히스토리

### 기록 보관소

- 세션 상태가 **Completed**로 변경되면 자동으로 기록 보관소로 이동
- 보관소에서는 **읽기 전용** — 결과/피드백 수정 불가
- Admin만 Completed → In Progress로 **재오픈** 가능

### 검색 & 필터

| 기능 | 설명 |
|------|------|
| 세션명 검색 | 텍스트 검색 |
| 날짜 범위 필터 | 기간별 조회 |
| 결과 필터 | Fail 항목만 모아보기 등 |

### 활용

- 이전 버전 테스트 이력을 **지식 자산**으로 축적
- 신규 테스터가 과거 이력 참고 가능
- 새 세션 생성 시 과거 세션의 **카테고리/항목 구조를 템플릿으로 복사**

- 클릭 시 원본 크기 확대
- 서버에 파일 저장 (uploads/ 디렉토리)
